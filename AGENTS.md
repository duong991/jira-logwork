# Agent Instructions

<!-- HARNESS:BEGIN -->
## Harness

Start with the requested outcome, then use the repository and Jira instance as the systems of record. Read `docs/WORKFLOW.md` and only the material relevant to the task.

- Configuration in [`config.yaml`](config.yaml) is authoritative for Jira URL, API tokens, user mappings, and repository locations.
- Never write credentials or tokens into Git history.
- The standard daily work allocation is **8.0 hours** (1d).
- Any write operation affecting Jira or Tempo Timesheets (`create_jira_ticket`, `update_jira_ticket`, `log_work`) requires explicit user preview and approval before execution.
- Text sent to Jira (titles, descriptions, summaries, worklog comments) must never mention AI/Claude authorship.
- For work logging, follow the 5-step lifecycle: Scan Commits -> Match Active Tickets -> Draft Plan -> User Approval -> Execute & Verify in Tempo.
<!-- HARNESS:END -->

## Task Routing & Skills

Use the specialized skills in `.agents/skills/` (mirrored in `.claude/skills/`):

1. **`jira-worklog`**:
   - Quét commit theo ngày (`scan_daily_work`), phân bổ giờ, khớp ticket trong Sprint và log work vào Tempo Timesheets (`log_work`).
   - Trigger: *"logwork hôm nay"*, *"ghi log công việc"*, *"quét commit để log"*, `/logwork`.
2. **`jira-sprint-tracker`**:
   - Theo dõi tiến độ Sprint đang chạy, thống kê ticket hoàn thành và backlog (`get_my_sprints`, `get_my_tickets`).
   - Trigger: *"tiến độ sprint"*, *"sprint hiện tại có những ticket nào"*, *"xem sprint của tôi"*.
3. **`jira-ticket-manager`**:
   - Tạo mới hoặc cập nhật ticket Jira theo quy chuẩn VNPT (tiền tố `[BE]`/`[FE]`, estimate, mô tả).
   - Trigger: *"tạo ticket jira"*, *"cập nhật ticket"*.
4. **`jira-setup`**:
   - Phỏng vấn và khảo sát thiết lập `config.yaml` từ `config.example.yaml` theo phương pháp Grill-me (rounds, frontier, auto facts-finding).
   - Trigger: *"setup jira"*, *"cấu hình jira"*, *"hướng dẫn setup config"*, `/setup`, `/jira-setup`.

## Hard Invariants

- A read-only query (status, view sprint, list tickets) must never mutate Jira or Tempo state.
- Always verify worklogs against Tempo Timesheets using `get_tempo_worklogs` after logging.
- AI authorship strings (`claude`, `anthropic`, `co-authored-by`, `generated by ai`) are strictly rejected.
- When creating any Jira ticket in project `NCPTWORK`, the following fields are strictly mandatory:
  * **Mã SPDA (`customfield_13100`):** `ATTT` (id: 13100) -> `Chung/CPCATTTT` (id: 13270).
  * **Công đoạn (`customfield_13000`):** `Nghiên cứu, phát triển, nâng cấp` (id: 13000).
  * **Due Date (`duedate`):** Bắt buộc ngày kết thúc (mặc định cuối tháng).
  * **Sprint (`customfield_10105`):** Gán vào Sprint active đang chạy.
